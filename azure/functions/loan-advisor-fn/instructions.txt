IMPORTANT — Flex vs classic Consumption
---------------------------------------
loan-advisor-func-app is Flex Consumption. Runtime is set at create time
(Portal → Overview shows Node 22). Do NOT add these app settings on Flex:
  FUNCTIONS_WORKER_RUNTIME      ← not used / portal may reject
  FUNCTIONS_EXTENSION_VERSION
  WEBSITE_NODE_DEFAULT_VERSION

FUNCTIONS_WORKER_RUNTIME=node in local.settings.json is LOCAL ONLY (for func CLI).

Endpoints (route prefix /api):
  POST /api/loanAdvisor
  POST /api/leOcr          — Loan Estimate OCR (PDF text or image → structured fields)
  POST /api/refiCheck
  POST /api/refiWatch
  Timer refiCron — Mon & Thu 14:00 UTC
