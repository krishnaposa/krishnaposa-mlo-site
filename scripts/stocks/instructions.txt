#   fallback PIE_OTM_PCT=0.06 if no delta; min_open_interest=100, max_spread_pct=15,
#   min_credit_width=0.10 (PCS_MIN_CREDIT_WIDTH / PCS_MIN_CREDIT_WIDTH_C)
# Entry funnel: PCS_FUNNEL=grade (default, Grade A/B/C excl REDUCE/SELL) | buy (pie_analyze default) | all (pie_analyze --all)
# Entry: earnings blocked when report before spread expiry (PCS_BLOCK_EARNINGS=1)
# Azure PCS email (morning pcs_morning + optional evening if MONITOR_EMAIL_INCLUDE_PCS=1):
#   monitoring/pcs_opportunities.py — pie scanner splits Grade A/B vs Grade C into two tables
#   PCS_OPPORTUNITIES_ENABLED=1 (default), tickers from blob signals/my_tickers.txt else local_list+holdings_list
#   Local adhoc: ./run_pcs_morning_adhoc.sh (PIE_TICKERS_FILE, PCS_POSITIONS_FILE)
#   Columns: Ticker, Grade, Signal, Expiry, DTE, Short, Long, Width, Credit, MaxRisk, Credit%, ShortΔ, OTM%, IV%, 1YTouch%
#   Ranked by ShortΔ sweet (~0.20–0.24) + OTM buffer + non-extreme Credit% + 1Y Touch% + Grade (not raw Credit%)
#   1YTouch% = last-year same-OTM%/same-DTE windows where daily low tagged short barrier (soft rank, not a reject)
#   PIE_TARGET_DTE=35  PCS_SHORT_DELTA_MIN=0.18  PCS_SHORT_DELTA_MAX=0.28  PCS_SHORT_DELTA_TARGET=0.22
#   PIE_SPREAD_WIDTH_PCT=0.03  PIE_MAX_PCS_CANDIDATES=12 (per grade group)
#   Open positions lifecycle: monitoring/pcs_lifecycle.py reads signals/positions.json (PCS_LIFECYCLE_ENABLED=1)
#   Technical second opinion: monitoring/pcs_recommendations.py (PCS_RECOMMENDATIONS_ENABLED=1)
#     Scores idea + open underlyings on short-put buffer, credit/width, Grade/Signal,
#     breakdown/spike/earnings — Alpha Trend is soft only. Labels: PCS READY / CAUTION / WAIT / AVOID
#   Local adhoc: PCS_POSITIONS_FILE=scripts/stocks/positions.json (see run_email_adhoc.sh)
#   Holdings / momentum: trailing stop only (no relative-strength exits)

# positions.json shape:
#   {"swings": [{"symbol","entry_price","entry_date","shares","stop_price"}],
#    "spreads": [{"symbol","short_put","long_put","expiration","credit","entry_date","contracts"}],
#    "pmcc": [{"symbol","long_call","long_expiration","long_debit","entry_date","contracts",
#              "short_call","short_expiration","short_credit","short_entry_date"}]}

# PMCC morning email (pmcc_morning timer ~10:30 ET + run_pmcc_morning_adhoc.sh):
#   monitoring/pmcc_opportunities.py — stock score + LEAP + short-call plan
#   PMCC_OPPORTUNITIES_ENABLED=1, tickers from PIE_TICKERS_FILE / my_tickers.txt
#   Score weights: 2yr thesis 30% (1Y/3M returns + YoY growth), fundamentals 30% (rev/earn/margin/P/S)
#   PMCC_BLOCK_FUND_FAIL=1 blocks FAIL verdict (mcap, shrinking rev, extreme P/S)
#   PMCC_MODE=core (core|aggressive) — aggressive skips FAIL fundamentals block
#   PMCC_BLOCK_NEG_1Y=1 blocks negative 1Y return
#   PMCC_EARNINGS_BLOCK_DAYS=7 blocks ideas with earnings within N days
#   Structure: breakeven ≤ 5% above spot (PMCC_MAX_BREAKEVEN_PCT_ABOVE_SPOT; ideal ≤ 0%)
#   Short: Δ 0.15–0.25; picks max MonthlyOnDebit% across 25–55 DTE (PMCC_MIN_MONTHLY_ON_DEBIT=1)
#   Score: thesis 25%, fund 25%, short income 20%, liq/IV/trend 10% each
#   PMCC_MIN_SCORE=6.0  PMCC_PREFILTER_N=120  PMCC_MAX_CHAIN_ANALYSIS=80  PMCC_MAX_CANDIDATES=12
#   monitoring/pmcc_lifecycle.py — LEAP exit + short-call management

#   Otherwise: close short at 50%, roll if challenged, keep selling calls

Phase	    When it triggers (defaults)	   What it means
EXIT        Profit% ≥ 50%                   You’ve captured enough premium — time to take profit and close.
STOP        Profit% ≤ −100%                 Loss is about 1× the credit collected — close to cap damage.
DEFENSIVE   Buffer% < 0                     Stock is under the short put — spread is in trouble; defend (close, roll, or hedge).
ROLL        DTE < 14 and Buffer% < 3%       Expiry is close and price is tight to the short strike — consider rolling out/down.
MANAGE      DTE ≤ 21                        Entering the “decision window” — actively decide to close or roll before expiry.
OPENED      None of the above               Healthy early/mid trade — no urgent change.
